# Nissan Fleet Case Analysis Dashboard

## Project Overview

This project analyzes fleet-related customer cases across Nissan dealerships to identify operational bottlenecks, monitor dealer performance, and improve case resolution efficiency.

## Business Problem

Fleet customers require timely resolution of vehicle concerns. Delays can negatively impact customer satisfaction, vehicle uptime, and operational efficiency.

## Tools Used

- Power BI
- Excel
- Business Intelligence
- Data Visualization
- Data Analysis

## Dashboard Components

### Open Cases per Dealer
Analyzes the distribution of active cases across dealerships.

### Top 5 Longest Open Cases
Identifies the longest unresolved cases.

### Delay Root Cause Analysis
Examines major delay drivers:
- Parts Availability
- Technical Delays
- Dealer Delays
- Customer Delays
- Other

## Key Findings

- Parts availability accounts for approximately 58% of delays.
- A high concentration of open cases exists at specific dealerships.
- Most long-running cases are driven by availability issues.

## Recommendations

- Improve parts procurement processes.
- Prioritize long-running availability-related cases.
- Strengthen dealer escalation processes.
- Monitor dealership workloads more closely.

## Business Value

The dashboard enables data-driven decision-making and helps improve customer satisfaction, operational performance, and case turnaround times.
